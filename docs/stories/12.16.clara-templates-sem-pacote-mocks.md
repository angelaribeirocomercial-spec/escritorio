# Story 12.16: Templates da Clara sem pacote de mocks

## Status

Done

## Story

Como time de produto,
quero que os templates estaticos da Clara fiquem no proprio servico,
para que o runtime da aplicacao nao dependa de `@lexia/mocks`.

## Acceptance Criteria

1. O workspace da Clara deixa de importar `@lexia/mocks`.
2. Os templates de resposta continuam disponiveis para Clara e LexIA legado.
3. O helper `getClaraFixtureByContextKey` continua funcionando com fallback.
4. Os testes de guarda validam ausencia de `@lexia/mocks` no runtime principal.
