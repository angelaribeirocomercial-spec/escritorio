# Story 12.7: Vertical de tarefas real e agenda operacional com Clara

## Status

Done

## Story

Como time de produto,  
quero migrar a vertical de tarefas para dados reais e conectar a agenda operacional ao fluxo da Clara,  
para que a execucao do escritorio deixe de depender de mocks e a camada operacional fique coerente com clientes, casos, processos e documentos.

## Acceptance Criteria

1. O service de `tarefas` usa Supabase como fonte primaria em vez de `@lexia/mocks`.
2. `Agenda > Tarefas` renderiza lista real com estados `loading`, `error` e `empty`.
3. O detalhe da tarefa trata indisponibilidade controlada e preserva o fluxo de retorno para a agenda e a Clara.
4. A Clara passa a usar tarefas reais em seletores, metricas e artefatos operacionais centrais.

## Tasks

- [x] Criar schema, RLS e seed da vertical de tarefas
- [x] Migrar `get-tasks.ts` para Supabase
- [x] Atualizar `Agenda > Tarefas` com estados controlados
- [x] Padronizar loading e erro no detalhe da tarefa
- [x] Atualizar Clara e agenda para ler tarefas reais
- [x] Atualizar testes de guarda

## Tests

- Leitura de tarefas pela tabela real
- Agenda de tarefas com estado controlado
- Presenca de loading em lista e detalhe
- Clara lendo seletores de tarefas reais

## Definition of Done

- Tarefas operando em base real
