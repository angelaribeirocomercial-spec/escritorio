## Story

**As a** legal operations team member,  
**I want** a robust task module with list, board, and operational context,  
**so that** I can execute banking-law workflows with clarity and accountability.

## Acceptance Criteria

1. The tarefas module shows a premium list view with realistic legal-operational task records.
2. The list exposes key task fields including titulo, descricao, caso, cliente, responsavel, prazo interno, prioridade, status, and checklist progress.
3. The module includes an operational board experience that simulates lista, kanban, and agenda/calendario context.
4. Each task links to an individual task page with structured operational context and checklist detail.
5. The module uses coherent mock task data connected to existing client and case records, including suggested checklist logic by claim type.
6. The implementation remains aligned with the existing tenant-aware workspace foundation.
