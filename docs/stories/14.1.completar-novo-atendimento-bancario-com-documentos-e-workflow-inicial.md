## Story

**Como** operadora do escritorio bancario,  
**quero** abrir cliente, caso, nicho e documentos em uma unica jornada confiavel,  
**para que** o caso ja nasca pronto para seguir o workflow correto do nicho piloto.

## Product Intent

Esta story abre o nucleo operacional do produto. Ela substitui o estado parcial de onboarding por uma entrada unica realmente coerente com o PRD mestre v2.

## Acceptance Criteria

1. A jornada `Novo atendimento bancario` permite cadastrar cliente, dados do caso, nicho, objetivo inicial e documentos na mesma experiencia principal.
2. O fluxo grava cliente, caso e vinculos documentais sem abrir rotas paralelas obrigatorias.
3. O nicho piloto `Revisional de contratos (veiculos)` instancia workflow inicial ao concluir o onboarding.
4. O onboarding cria checklist documental e tarefas iniciais minimas do caso.
5. Ao concluir, o sistema redireciona para o cockpit do cliente com `clientId` e `caseId` resolvidos.
6. O fluxo falha de forma controlada quando faltarem dados obrigatorios ou anexos essenciais.
7. `npm run lint`, `npm run typecheck` e `npm test` continuam verdes.
8. Checklist e file list da story sao atualizados antes de encerrar.
