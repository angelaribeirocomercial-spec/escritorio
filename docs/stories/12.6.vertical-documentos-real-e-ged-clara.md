# Story 12.6: Vertical de documentos real e GED com Clara

## Status

Done

## Story

Como time de produto,  
quero migrar a vertical de documentos para dados reais e conectar o GED ao hub da Clara,  
para que a leitura documental deixe de depender de mocks e o fluxo de comparacao avance sobre a base real.

## Acceptance Criteria

1. O service de `documentos` usa Supabase como fonte primaria em vez de `@lexia/mocks`.
2. A tela principal do GED renderiza lista real com estados `loading`, `error` e `empty`.
3. O detalhe do documento trata indisponibilidade controlada e continua orientando o fluxo para a Clara.
4. A Clara passa a usar documentos reais em seletores e artefatos centrais.

## Tasks

- [x] Criar schema, RLS e seed da vertical de documentos
- [x] Migrar `get-documents.ts` para Supabase
- [x] Atualizar GED principal em `meus-arquivos`
- [x] Padronizar loading e erro no detalhe
- [x] Atualizar Clara para ler documentos reais
- [x] Atualizar testes de guarda

## Tests

- Leitura de documentos pela tabela real
- GED principal com estado controlado
- Presenca de loading em lista e detalhe
- Clara lendo seletores de documentos reais

## Definition of Done
