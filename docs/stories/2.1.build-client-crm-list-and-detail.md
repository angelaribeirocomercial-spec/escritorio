## Story

**As a** legal team member,  
**I want** a useful CRM juridico with client list and rich client detail,  
**so that** I can navigate real customer context instead of placeholders.

## Acceptance Criteria

1. The clientes module shows a premium list view with realistic client records.
2. The list exposes key CRM fields relevant to LexIA Bancaria, including status, banco, origem do lead, contrato, honorarios, and score de viabilidade.
3. Each client card or row links to an individual client page.
4. The individual client page shows a structured overview including core identity data, notes, documents, linked cases, and atendimento timeline.
5. The CRM uses coherent mock data that aligns with banking-law workflows.
6. The implementation stays compatible with the existing tenant-aware workspace foundation.
