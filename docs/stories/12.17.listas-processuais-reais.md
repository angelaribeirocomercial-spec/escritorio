# Story 12.17: Listas processuais reais

## Status

Done

## Story

Como usuario do escritorio,
quero ver publicacoes do Diario Oficial e andamentos processuais em listas reais,
para navegar do monitoramento ate o detalhe sem telas estaticas desconectadas.

## Acceptance Criteria

1. A lista de publicacoes do Diario Oficial consome `getOfficialDiaryPublications`.
2. A lista de andamentos automaticos consome `getProceduralUpdates`.
3. As duas listas possuem busca simples e estado controlado de falha.
4. As rotas possuem loading states.
