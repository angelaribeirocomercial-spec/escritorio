# Story 12.34: Linguagem mock e indicadores de documentos

## Status

Done

## Story

Como usuario das rotas de documentos e analise,
quero que textos visiveis nao mencionem mocks nem percentuais fixos,
para confiar que a interface separa dados reais de capacidades ainda indisponiveis.

## Acceptance Criteria

1. Detalhe de documento deixa de exibir "Preview mockado".
2. Seed de documentos deixa de gravar labels com "mockado".
3. Analise contratual e Clara revisional deixam de chamar estimativas de simulacao mockada.
4. Lista de documentos substitui `Utilizado: 0.0%` por indicador derivado da base real.
5. Testes de guarda cobrem esses residuos.
