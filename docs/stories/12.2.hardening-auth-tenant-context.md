# Story 12.2: Hardening de auth, tenant context e configuracao

## Status

Done

## Story

Como time de aplicacao,  
quero remover fallbacks silenciosos e fortalecer auth/tenant context,  
para que erros estruturais aparecam cedo e o produto opere de forma previsivel.

## Acceptance Criteria

1. `getSupabaseEnv()` nao mascara ambiente mal configurado com placeholders silenciosos fora do modo demo explicito.
2. `resolveWorkspaceContext()` nao trata falha estrutural de banco como tenant valido implícito.
3. O modo demo continua possivel, mas explicitamente separado do caminho de erro real.
4. Existem testes para login, sessao obrigatoria e resolucao de tenant context.
