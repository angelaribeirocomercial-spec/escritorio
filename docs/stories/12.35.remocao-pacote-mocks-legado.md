# Story 12.35: Remocao do pacote legado de mocks

## Status

Done

## Story

Como mantenedor do Brownfield,
quero remover o workspace `@lexia/mocks` depois que o runtime passou a usar fontes reais,
para evitar regressao acidental para fixtures estaticas.

## Acceptance Criteria

1. `@lexia/mocks` deixa de existir como path alias ativo.
2. O pacote `packages/mocks` deixa de ser workspace resolvido no lockfile.
3. Arquivos de fixtures legadas sao removidos do codigo ativo.
4. Testes de guarda validam ausencia de importacao no runtime principal.
