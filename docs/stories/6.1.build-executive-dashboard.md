## Story

**As a** managing partner or operations leader,  
**I want** an executive dashboard with actionable banking-law metrics and insights,  
**so that** I can monitor carteira, produtividade, urgencias, and LexIA signals from one screen.

## Acceptance Criteria

1. The dashboard shows premium cards with metrics derived from the existing client, case, document, and task modules.
2. The dashboard includes visual summaries for monthly evolution and case distribution by type and bank.
3. The dashboard surfaces operational lists for upcoming deadlines and urgent tasks.
4. The dashboard includes recent activity and a LexIA insights panel tied to the current mock operation.
5. The implementation remains aligned with the existing tenant-aware workspace foundation.
