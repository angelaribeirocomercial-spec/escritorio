# Story 13.3: Aliases de ambiente para validacao do upload

## Status

Done

## Story

Como operador tecnico,
quero que o runtime e o CLI aceitem as variaveis Supabase existentes no `.env`,
para validar o upload documental sem duplicar configuracao.

## Acceptance Criteria

1. Loader Supabase aceita `NEXT_PUBLIC_SUPABASE_URL` ou `SUPABASE_URL`.
2. Loader Supabase aceita `NEXT_PUBLIC_SUPABASE_ANON_KEY` ou `SUPABASE_ANON_KEY`.
3. CLI `documents:upload` carrega `.env` local antes de executar.
4. Testes de guarda cobrem os aliases.
