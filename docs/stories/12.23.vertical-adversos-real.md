# Story 12.23: Vertical adversos real

## Status

Done

## Story

Como usuario do modulo de pessoas,
quero consultar adversos e contatos/partes a partir da base real,
para que o diretorio de pessoas deixe de depender de arrays estaticos.

## Acceptance Criteria

1. Existe tabela real de `adversaries` com RLS e seed.
2. Existe service server-side para carregar adversos do tenant.
3. `pessoas/adversos` usa adversos reais.
4. `pessoas/[subpage]` usa adversos reais para advogados adversos e clientes reais para contatos/partes.
