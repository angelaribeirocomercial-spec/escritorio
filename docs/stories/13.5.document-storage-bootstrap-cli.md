# Story 13.5: Bootstrap de storage documental via CLI

## Status

Done

## Story

Como operador tecnico,
quero que o upload CLI consiga preparar o bucket documental quando ele nao existir,
para reduzir falha operacional na primeira validacao do tenant.

## Acceptance Criteria

1. O CLI inspeciona buckets antes do upload.
2. Se `tenant-documents` nao existir, o CLI cria o bucket privado.
3. O upload continua usando o mesmo bucket apos o bootstrap.
4. Testes de guarda cobrem inspeção e criacao do bucket.
