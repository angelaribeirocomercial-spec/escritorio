## Story

**Como** advogada do escritorio bancario,
**quero** que a peticao inicial seja montada a partir do dossie real e passe por revisao/aprovacao humana antes do handoff de distribuicao,
**para que** a saida juridica fique pronta para protocolar sem depender de placeholders soltos.

## Acceptance Criteria

1. A peticao inicial e montada a partir do dossie real do caso, incluindo fatos, fundamentos, pedidos, tutela, memoria economica e repeticao de indebito quando aplicavel.
2. O fluxo deixa claro quais trechos vieram de fatos confirmados do caso e quais dependem de revisao juridica humana.
3. O advogado consegue revisar, ajustar e aprovar a peticao antes de marcar o caso como `pronto para distribuir`.
4. O handoff de distribuicao so e liberado quando a peticao estiver em estado aprovado.
5. O produto nao simula protocolo automatico; ele apenas entrega uma peticao pronta e rastreavel para a etapa oficial seguinte.
6. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` permanecem verdes.
