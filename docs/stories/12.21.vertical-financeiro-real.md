# Story 12.21: Vertical financeiro real

## Status

Done

## Story

Como usuario do escritorio,
quero consultar receitas, despesas, transferencias e vencimentos a partir de dados persistidos,
para que o financeiro deixe de exibir apenas listas vazias estaticas.

## Acceptance Criteria

1. Existe tabela real de `financial_entries` com RLS e seed.
2. Existe service server-side para carregar lancamentos financeiros do tenant.
3. Receitas, despesas, transferencias e vencimentos usam o service real.
4. As paginas possuem estado de falha controlado, busca simples e loading state.
