# Story 12.5: Vertical de casos real com Clara contextual

## Status

Done

## Story

Como time de produto,  
quero migrar a vertical de casos para dados reais e usar esse contexto dentro da Clara,  
para que o hub da IA opere sobre a base bancaria real sem reabrir uma navegacao paralela de casos.

## Acceptance Criteria

1. O service de `casos` usa Supabase como fonte primaria em vez de `@lexia/mocks`.
2. A rota `casos` continua colapsada em `processos`, sem recriar uma segunda experiencia concorrente.
3. A Clara passa a ler `casos`, `clientes` e `processos` reais para seletores e artefatos centrais.
4. Existem testes de guarda cobrindo a leitura real da vertical.

## Tasks

- [x] Criar schema, RLS e seed da vertical de casos
- [x] Migrar `get-cases.ts` para Supabase
- [x] Preservar o redirect de `casos` para `processos`
- [x] Atualizar backbone contextual da Clara
- [x] Atualizar testes de guarda

## Tests

- Leitura de casos pela tabela real
- Ausencia de dependencia primaria em `mockCases`
- Continuidade da navegacao colapsada em `processos`
- Clara lendo seletores com base real

## Definition of Done

- Casos operando em base real
- Clara usando contexto real para cliente, caso e processo
- Navegacao mantida sem duplicar telas
