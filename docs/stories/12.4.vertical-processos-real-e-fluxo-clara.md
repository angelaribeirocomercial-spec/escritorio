# Story 12.4: Vertical de processos real com fluxo Clara centralizado

## Status

Done

## Story

Como time de produto,  
quero migrar a vertical de processos para dados reais e transformar a Clara em ponto de continuidade do fluxo,  
para que o usuario entenda com clareza onde operar o processo e onde aprofundar a leitura assistida.

## Acceptance Criteria

1. A vertical de `processos` usa Supabase como fonte primaria em vez de `@lexia/mocks`.
2. A listagem e o detalhe de processos possuem estados padronizados de `loading`, `error` e `empty`.
3. As telas de cliente e processo tratam a Clara como hub dedicado de continuidade, sem repetir um handoff longo espalhado na pagina.
4. Existem testes cobrindo a leitura real da vertical e os arquivos de loading.

## Tasks

- [x] Criar schema, RLS e seed da vertical de processos
- [x] Migrar service layer para Supabase
- [x] Padronizar estados de listagem e detalhe

- [x] Atualizar testes de guarda
