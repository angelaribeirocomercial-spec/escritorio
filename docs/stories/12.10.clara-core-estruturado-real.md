# Story 12.10: Clara core estruturado real

## Status

Done

## Story

Como time de produto,  
quero migrar o core estruturado da Clara para fontes reais,  
para que a classificacao, a trilha de auditoria e os adapters internos usem cliente, caso, processo e documento do tenant ativo em vez de mocks espalhados.

## Acceptance Criteria

1. `get-clara-structured-core.ts` resolve contexto principal por services reais.
2. `clara-source-adapters.ts` resolve contexto principal por services reais.
3. `get-clara-workspace.ts` continua funcionando com o core estruturado agora assíncrono.
4. Os testes de guarda passam a validar a ausencia de dependencia primaria em mocks nesses dois pontos.
