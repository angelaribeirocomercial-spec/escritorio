## Story

**Como** operadora do escritorio bancario,
**quero** excluir um cliente e todos os fluxos derivados dele,
**para que** eu consiga limpar dados de teste ou casos descartados sem deixar residuos operacionais no workspace.

## Product Intent

Este corte adiciona a exclusao destrutiva no cockpit do cliente com remocao em cascata dos registros gerados a partir dele, preservando a confianca dos dados e sem criar exclusao falsa ou parcial.

## Acceptance Criteria

1. A tela do cliente exibe um botao de exclusao destrutiva claramente identificado.
2. A exclusao remove o cliente e os registros gerados a partir dele no tenant ativo.
3. O fluxo nao deixa residuos de teste ou dados derivados vinculados ao cliente excluido.
4. Apos excluir, o usuario retorna para a lista de clientes.
5. `npm run lint`, `npm run typecheck` e `npm test` permanecem verdes.
