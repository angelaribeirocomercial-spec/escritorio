## Story

**As a** legal team member,  
**I want** a useful GED juridico with document list, detail, and contextual actions,  
**so that** I can navigate the banking-law document base with IA-oriented workflows.

## Acceptance Criteria

1. The documentos module shows a premium list view with realistic banking-law document records.
2. The list exposes key GED fields including tipo documental, cliente, caso, tags, category, and IA status.
3. Each document links to an individual document page.
4. The individual document page shows a structured preview experience with metadata, linked client/case context, and contextual IA actions.
5. The module uses coherent mock document data connected to existing client and case records.
6. The implementation remains aligned with the existing tenant-aware workspace foundation.
