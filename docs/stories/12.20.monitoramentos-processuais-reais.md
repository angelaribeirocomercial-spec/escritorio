# Story 12.20: Monitoramentos processuais reais

## Status

Done

## Story

Como usuario do modulo de andamentos,
quero ver os processos monitorados a partir da base real,
para entender quais processos estao em monitoramento manual, OAB ou tribunal.

## Acceptance Criteria

1. A rota `andamentos/monitoramentos` consome `getProcesses`.
2. A tela mostra quotas derivadas dos processos reais.
3. A tela permite busca por processo, cliente, tribunal ou responsavel.
4. A rota possui estado de erro controlado e loading state.
