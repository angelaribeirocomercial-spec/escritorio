# Story 13.2: Upload documental real pela interface

## Status

Done

## Story

Como usuario autorizado do escritorio,
quero enviar documentos pela interface usando o contrato CLI/storage ja criado,
para alimentar o GED real sem voltar a placeholders de upload.

## Acceptance Criteria

1. A rota `documentos/enviar-arquivos` deixa de exibir estado indisponivel quando casos reais carregam.
2. A tela exige arquivo, caso real, tipo documental e categoria.
3. A server action envia o arquivo ao bucket `tenant-documents`.
4. A server action registra metadata na tabela `documents`.
5. Falhas removem o arquivo do storage quando a metadata nao e persistida.
6. Testes de guarda cobrem UI real e server action.
