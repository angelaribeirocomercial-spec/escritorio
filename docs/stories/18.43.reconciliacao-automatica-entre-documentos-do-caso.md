## Story

**Como** operadora do escritorio bancario,  
**quero** que o sistema reconcilie automaticamente contrato, extratos, historico e comprovantes do mesmo caso,  
**para que** a confianca do dossie suba sem digitacao manual e a revisao humana fique limitada a divergencias reais.

## Acceptance Criteria

1. A extracao estruturada do documento-base pode ser enriquecida por campos confirmados em outros documentos do mesmo caso.
2. O sistema sobe a confianca quando houver corroboracao entre documentos.
3. O sistema abre excecao apenas quando houver conflito material entre evidencias documentais.
4. Uploads de novos documentos ressicronizam o contrato principal do caso automaticamente.
5. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` permanecem verdes.
