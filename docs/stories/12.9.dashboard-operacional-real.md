# Story 12.9: Dashboard operacional real

## Status

Done

## Story

Como time de produto,  
quero migrar o dashboard para dados reais,  
para que a visao executiva reflita a operacao atual do tenant com clientes, casos, tarefas, documentos e agenda ja persistidos.

## Acceptance Criteria

1. O service de `dashboard` usa as fontes reais ja migradas em vez de `@lexia/mocks`.
2. O dashboard trata indisponibilidade controlada da camada real.
3. O dashboard continua exibindo metricas, atalhos operacionais e contadores consolidados.
4. Os testes de guarda passam a validar a ausencia de dependencia primaria em mocks no dashboard.
