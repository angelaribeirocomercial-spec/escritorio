## Story

**Como** gestora do escritorio bancario,
**quero** que a Clara opere sobre o dossie real do caso e dispare a acao central `Analisar Caso com Clara`,
**para que** a IA deixe de ser uma superficie separada e passe a orquestrar o fluxo juridico bancario dentro do contexto do caso.

## Product Intent

Esta story fecha a cadeia do dossie unico.

Clara nao substitui o caso, o contrato, os documentos nem os calculos. Ela usa tudo isso para explicar, orientar e preparar a revisao humana.

## Acceptance Criteria

1. Clara responde com base no cliente, caso, contrato e documentos reais do dossie.
2. A acao `Analisar Caso com Clara` deixa claro o status do fluxo.
3. O sistema registra historico, fontes e minutas associadas ao caso.
4. Clara atua como camada contextual do caso, nao como modulo isolado.
5. `npm run lint`, `npm run typecheck` e `npm test` permanecem verdes.
