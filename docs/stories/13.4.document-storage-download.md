# Story 13.4: Download seguro de documento armazenado

## Status

Done

## Story

Como usuario autorizado do GED,
quero baixar o arquivo real vinculado ao documento,
para fechar o ciclo entre upload, metadata e acesso seguro ao storage.

## Acceptance Criteria

1. Existe service para gerar signed URL de storage.
2. Signed URL usa expiracao curta por padrao.
3. Detalhe do documento exibe botao de download apenas quando ha URL assinada.
4. Detalhe exibe metadados de storage, MIME e tamanho.
5. Testes de guarda cobrem o service e a UI de download.
