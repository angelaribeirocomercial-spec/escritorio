# Story 13.1: Upload documental via CLI com Supabase Storage

## Status

Done

## Story

Como operador tecnico do escritorio,
quero registrar documentos reais via CLI antes da UI,
para cumprir o fluxo CLI First e preparar a vertical de upload com persistencia real por tenant.

## Acceptance Criteria

1. Existe comando CLI para enviar arquivo ao Supabase Storage.
2. O comando registra metadata na tabela `documents` com tenant, cliente, caso e metadados de storage.
3. O schema versionado inclui bucket/path/mime/size para documentos.
4. A migration cria bucket privado e policies de storage por tenant.
5. Testes de guarda validam o comando e a ausencia de upload falso como caminho principal.
