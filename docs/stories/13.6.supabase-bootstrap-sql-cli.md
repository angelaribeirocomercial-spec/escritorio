# Story 13.6: SQL consolidado para bootstrap Supabase

## Status

Done

## Story

Como operador tecnico,
quero gerar um unico SQL de bootstrap do projeto,
para aplicar schema, policies e seeds no Supabase sem executar dezenas de arquivos manualmente.

## Acceptance Criteria

1. Existe comando CLI para gerar SQL consolidado.
2. O arquivo final inclui migrations, policies e seeds em ordem.
3. O output e escrito em `supabase/out/001_full_bootstrap.sql`.
4. Existe runbook simples para aplicacao manual no SQL Editor.
5. Testes de guarda cobrem o builder.
