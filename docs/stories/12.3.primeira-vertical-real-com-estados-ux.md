# Story 12.3: Primeira vertical real com estados de UX e testes

## Status

Done

## Story

Como time de produto,  
quero migrar a primeira vertical de negocio de mocks para dados reais com estados de UX padronizados,  
para que a plataforma deixe de ser apenas demonstrativa e ganhe operacao confiavel.

## Acceptance Criteria

1. Um modulo priorizado usa repositorio real em vez de `@lexia/mocks` como fonte primaria.
2. O modulo possui estados `loading`, `error` e `empty` padronizados.
3. O fluxo tem testes cobrindo renderizacao e leitura de dados.
4. A shell visual continua coerente com o restante do produto.
