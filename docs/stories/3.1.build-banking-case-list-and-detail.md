## Story

**As a** legal team member,  
**I want** a useful banking-case module with list and rich case detail,  
**so that** I can operate the central juridical workspace of LexIA Bancaria.

## Acceptance Criteria

1. The casos module shows a premium list view with realistic banking-case records.
2. The list exposes key case fields including cliente, banco reu, tipo de demanda, fase, status, tese principal, risco, and valor estimado.
3. Each case links to an individual case page.
4. The individual case page shows a structured case workspace including overview, strategy, linked documents, linked tasks, linked deadlines, and LexIA insights.
5. The module uses coherent mock case data connected to the CRM client records.
6. The implementation remains aligned with the existing tenant-aware workspace foundation.

## Dev Notes

### Relevant Context

- The banking-case module is the central juridical and operational workspace of the product. [Source: docs/product/lexia-bancaria/system-map.md#Core Modules]
- Each case should expose client, bank, claim type, phase, thesis, legal risk, and strategy. [Source: docs/product/lexia-bancaria/system-map.md#Core Modules]
- The case page is the most important screen in the system and must concentrate overview, documents, tasks, deadlines, and LexIA insights. [Source: docs/product/lexia-bancaria/system-map.md#Most Important Screens]
- The backlog explicitly sequences the case module right after the CRM module. [Source: docs/product/lexia-bancaria/backlog-prioritization.md#Recommended First Stories]
