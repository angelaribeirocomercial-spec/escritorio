# Story 12.22: Fallback canonico do financeiro

## Status

Done

## Story

Como usuario do modulo financeiro,
quero que subrotas genericas conhecidas apontem para as rotas reais,
para evitar telas antigas com contadores artificiais.

## Acceptance Criteria

1. `financeiro/[subpage]` deixa de renderizar lista vazia estatica.
2. Subrotas conhecidas redirecionam para suas rotas canonicas.
3. Subrotas desconhecidas continuam retornando `notFound`.
4. Os testes de guarda validam o fallback.
