## Story

**Como** operadora do escritorio bancario,  
**quero** que a peca superveniente sugerida pelo acompanhamento ja aponte para a minuta contextual da Clara,  
**para que** o fluxo fique completo do andamento ate a redacao assistida, com o humano apenas conferindo e conduzindo.

## Analyst Diagnosis

Depois de `18.48`, o sistema ja:

- sugere a proxima peca superveniente
- pre-registra essa peca no acompanhamento processual

O gap final e de continuidade operacional:

- a peca sugerida ainda nao abre automaticamente a trilha de minuta contextual da Clara
- isso mantem um pequeno salto manual entre acompanhamento e redacao assistida

Conclusao do `@analyst`:

- o ultimo slice correto e ligar a peca sugerida ao editor/minuta contextual da Clara
- isso fecha o ciclo `andamento -> peca cabivel -> minuta pronta para revisar`

## Acceptance Criteria

1. A peca superveniente sugerida no processo oferece link ou acao direta para abrir a minuta contextual correspondente.
2. O contexto da minuta reaproveita processo, caso, cliente e andamento gatilho quando disponiveis.
3. O fluxo continua honesto: a Clara prepara a base redacional, mas a revisao/protocolo seguem humanos.
4. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` permanecem verdes.
