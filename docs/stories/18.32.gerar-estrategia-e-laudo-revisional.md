## Story

**Como** gestora do escritorio bancario,
**quero** que o sistema gere estrategia e laudo revisional a partir do dossie unico,
**para que** o advogado tenha uma saida tecnica e juridica consolidada antes da peticao.

## Product Intent

Esta story consolida a fase analitica do caso.

`Estrategia` responde o que fazer.
`Laudo` responde o que foi encontrado e como foi calculado.

## Acceptance Criteria

1. O sistema produz um resumo estrategico com tese, riscos, pedidos e proximos passos.
2. O laudo revisional inclui dados do cliente, contrato, metodologia e comparacao.
3. A saida nao substitui revisao humana.
4. A estrategia e o laudo consomem o mesmo caso e os mesmos dados juridicos.
5. `npm run lint`, `npm run typecheck` e `npm test` permanecem verdes.
