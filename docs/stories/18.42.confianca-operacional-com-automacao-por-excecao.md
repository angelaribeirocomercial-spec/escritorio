## Story

**Como** operadora do escritorio bancario,  
**quero** que o sistema calcule a confianca operacional do documento e do caso e autoaprove o que estiver consistente,  
**para que** o humano atue so por seguranca e por excecao, sem precisar preencher campos manualmente.

## Acceptance Criteria

1. O documento passa a expor estado de automacao `autonomo`, `assistido` ou `bloqueado`.
2. A leitura estruturada pode ser autoaprovada quando os campos criticos estiverem consistentes.
3. O dossie do caso passa a mostrar uma confianca operacional unica baseada em OCR, calculo, BACEN e peticao.
4. O operador visualiza blockers reais quando o caso ainda nao puder seguir sozinho.
5. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` permanecem verdes.
