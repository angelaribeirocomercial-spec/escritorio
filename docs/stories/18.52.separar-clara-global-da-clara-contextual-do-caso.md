## Story

**Como** usuario do escritorio,  
**quero** abrir a Clara do menu lateral como uma assistente global do sistema e continuar usando a Clara do dossie como assistente contextual do caso,  
**para que** a experiencia global nao dependa de cliente/caso e o dossie continue preservando o contexto juridico completo de cada caso.

## PM Direction

O produto passa a separar explicitamente duas experiencias:

1. `Clara global`
2. `Clara do caso`

Direcao obrigatoria:

- `/clara` deve abrir sem `client`, `case`, `process` ou `document`
- a Clara lateral deve ser uma assistente global para buscas, leituras e orientacoes avulsas
- a Clara do dossie continua contextual e ligada ao caso
- a nova pagina da Clara nao substitui o dossie nesta etapa
- os modulos `Triagem`, `Intimacao`, `Peca`, `Jurisprudencia`, `Acompanhamento`, `Estrategia` e `Revisao` ainda nao ganham papel de substituicao do dossie

## Acceptance Criteria

1. A rota `/clara` abre como Clara global sem exigir `client`, `case`, `process` ou `document`.
2. A Clara global nao exibe estados de indisponibilidade causados por falta de contexto minimo de caso.
3. A Clara contextual dentro do dossie continua funcionando com contexto completo do caso.
4. A nova pagina da Clara nao substitui o dossie nesta story.
5. O fluxo principal da Clara lateral deixa de empurrar o usuario para uma experiencia que parece cockpit de caso obrigatorio.
6. A demo e os redirects principais da Clara devem respeitar a decisao de produto aprovada para Clara global vs Clara do caso.
7. `npm run lint`, `npm run typecheck`, `npm test` e `npm run build` permanecem verdes.

## Tasks / Subtasks

- [x] Task 1 (AC: 1, 2)
  - [x] Restaurar `/clara` como experiencia global, sem dependencia obrigatoria de `client/case/process/document`.
  - [x] Ajustar o guard de contexto minimo para atuar apenas na Clara contextual do caso, e nao na Clara global.
- [x] Task 2 (AC: 3, 4)
  - [x] Preservar a Clara dentro do dossie como experiencia contextual do caso.
  - [x] Garantir que nenhuma mudanca nesta story tente substituir o dossie pela nova Clara.
- [x] Task 3 (AC: 5, 6)
  - [x] Revisar os redirects e pontos de entrada da Clara para respeitar a separacao de produto.
  - [x] Impedir que a Clara lateral pareca uma pagina “presa” a caso quando aberta como assistente global.
- [x] Task 4 (AC: 7)
  - [x] Rodar `npm run lint`.
  - [x] Rodar `npm run typecheck`.
  - [x] Rodar `npm test`.
  - [x] Rodar `npm run build`.
