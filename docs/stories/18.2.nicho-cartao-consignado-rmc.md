## Story

**Como** operadora do escritorio bancario,
**quero** abrir o nicho de cartao consignado / RMC como fluxo bancario real,
**para que** a entrada do caso, o workflow e a Clara reconhecam esse tipo de demanda sem cair no ramo errado.

## Product Intent

Esta story fecha o segundo bloco da fase 5 do PRD mestre novo: ampliacao de nichos bancarios com suporte para cartao consignado / RMC.

## Acceptance Criteria

1. O dominio aceita `cartao-consignado` como nicho bancario valido.
2. O onboarding de novo atendimento reconhece e valida esse nicho.
3. O workflow do caso expõe um passo a passo especifico para cartao consignado / RMC.
4. A Clara classifica esse nicho corretamente e mostra o bloco operacional correspondente.
5. `npm run lint`, `npm run typecheck` e `npm test` continuam verdes.
